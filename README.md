### Bacula (community edition) packages

Bacula community edition packages used to be maintained and built by me; I gave a lot of time and energy for free to provide RPM & DEB packages to the Community for free.

For further details, check the [Bacula](https://wwww.bacula.org) project website, and [this link](https://www.bacula.org/bacula-binary-package-download/) for the .rpm and .deb packages.

### mhVTL GUI

[mhvtl](https://github.com/markh794/mhvtl) is a Linux-based Virtual Tape Library maintained by [Mark Harvey](https://github.com/markh794).

I’ve already forked the original Git repository and started working on improvements and bug fixes.

For further details, please refer to the [mhvtl-gui](https://github.com/dfranco/mhvtl-gui) repository on GitHub.
